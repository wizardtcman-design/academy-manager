# راهنمای اتصال ربات تلگرام به سرور Cloudflare (برای مدیر آموزشگاه)

این سند فقط **مرحلهٔ یک‌بارهٔ استقرار سرور** را توضیح می‌دهد. بعد از این مرحله،
اتصال ربات، ثبت وبهوک و آزمایش اتصال همه **از داخل خود اپلیکیشن** و خودکار
انجام می‌شود (تنظیمات ← ربات تلگرام) و نیازی به هیچ دستور فنی نیست.

---

## ۱) چه چیزهایی از قبل خودکار است؟ (هرگز دستی انجام ندهید)

| کار | چه کسی/کِی |
|---|---|
| ثبت وبهوک تلگرام با رمز امن اختصاصی هر آموزشگاه | خودکار هنگام زدن «اتصال ربات» در اپ |
| نگهداری توکن ربات (در دیتابیس سرور، فقط برای آموزشگاه خودش) | خودکار؛ توکن هرگز به اپ برگردانده نمی‌شود |
| ارسال یادآوری‌ها و پیام‌ها حتی وقتی اپ بسته است | Cron سرور (هر دقیقه) |
| جداسازی ربات/دادهٔ هر آموزشگاه از بقیه | خودکار (X-Academy-Id + ACADEMY_IDS) |
| آزمایش واقعی اتصال (سرور + تلگرام + وبهوک) | دکمهٔ «آزمایش اتصال» در اپ |

## ۲) مرحلهٔ یک‌بارهٔ استقرار سرور (فقط یک بار)

این مرحله به محیط امن Cloudflare نیاز دارد و باید **یک‌بار** توسط مالک حساب یا
توسعه‌دهنده انجام شود. هیچ‌کدام از این اطلاعات به اپ یا APK وارد نمی‌شود:

1. **نصب ابزار محلی در رایانهٔ مورد اعتماد**: `npm install` در پوشهٔ
   `cloudflare-telegram-backend` و ورود امن: `npx wrangler login`
   (یا در GitHub Actions از Secretهای مخزن استفاده کنید).
2. **دیتابیس D1**: ساخت/اتصال دیتابیس با نام `DB` و اجرای مهاجرت‌های
   `migrations/0001..0011` به ترتیب (`wrangler d1 migrations apply`).
3. **Secretهای Worker** — با `wrangler secret put`:
   - `API_SECRET_KEY` — یک عبارت رمز بلند و تصادفی که خودتان انتخاب می‌کنید.
     **همین مقدار** بعداً در اپ در فیلد «کلید API سرور» وارد می‌شود.
   - `WEBHOOK_SECRET` — فقط برای ربات سراسری قدیمی؛ ربات‌های هر آموزشگاه
     رمز اختصاصی خودشان را خودکار می‌گیرند.
   - توکن ربات تلگرام **نیازی به Secret جداگانه ندارد** — از داخل اپ وارد و
     در دیتابیس آموزشگاه ذخیره می‌شود (مسیر `/api/bot/connect`).
4. **متغیرهای Worker** (در `wrangler.toml` یا داشبورد):
   - `PUBLIC_BASE_URL` = آدرس کامل Worker (مثل `https://academy-manager1.NAMA.workers.dev`)
   - `ACADEMY_IDS` = شناسه‌های آموزشگاه‌ها با کاما (مثل `default`)
   - `ENVIRONMENT` = `production`
5. **استقرار**: `npx wrangler deploy`

**Cloudflare Account ID و API Token پنل Cloudflare** فقط در همین محیط استقرار
(wrangler یا GitHub Actions Secrets) استفاده می‌شوند؛ **هرگز** در اپ، در فرم
اتصال، در کد یا داخل APK قرار نمی‌گیرند.

## ۳) بعد از استقرار — داخل اپ (بدون کار فنی)

1. تنظیمات ← ربات تلگرام
2. فیلدهای «آدرس سرور» و «کلید API سرور» را کامل کنید (زیر هر فیلد راهنمای
   کامل فارسی وجود دارد).
3. توکن ربات را از `@BotFather` بگیرید و در «توکن ربات تلگرام» بگذارید.
4. دکمهٔ «اتصال ربات» را بزنید — وبهوک خودکار ثبت می‌شود.
5. دکمهٔ «آزمایش اتصال» را بزنید — وضعیت واقعی (ربات + وبهوک) نمایش داده
   می‌شود؛ اگر مشکلی باشد، علت و راه‌حل دقیق فارسی نشان داده می‌شود.

## ۴) عیب‌یابی سریع

| پیام بنر وضعیت | راه‌حل |
|---|---|
| کلید API سرور نادرست است | مقدار فیلد کلید را با `API_SECRET_KEY` روی Worker مقایسه کنید |
| آدرس سرور یا مسیر API اشتباه است | آدرس باید کامل و HTTPS باشد و به Worker شما برسد (۴۰۴ ⇒ آدرس غلط) |
| تلگرام توکن را نپذیرفت | در `@BotFather` با `/mybots` توکن را بررسی/تجدید کنید |
| وبهوک ثبت نشده / به آدرس دیگری می‌رود | دکمهٔ «بازیابی وبهوک» را بزنید |
| PUBLIC_BASE_URL تنظیم نیست | لینک امضای قرارداد و وبهوک غلط ساخته می‌شود؛ متغیر را روی آدرس Worker تنظیم کنید |
